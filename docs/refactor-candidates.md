- `outputMap(name)` and `makeEvalFn(spec)` are defined twice: `nnue/match-two-models.js` (lines 66, 76) and `nnue/tactics.js` (lines 20, 30). Evidence: `grep -nE "function (outputMap|makeEvalFn)" nnue/*.js selfplay-*.js tools/*/*.js`. `selfplay-worker-merged.js` has no copy. Extract to e.g. `nnue/lib/eval-fn.js`. Risk med (match.yml runs match-two-models.js; verify with a short match).
- Dead exports: neither file uses `module.exports`, so none.
- Dependencies: `@tensorflow/tfjs` and `@tensorflow/tfjs-backend-wasm` are both required by `nnue/train.js` (lines 6-7). No unused dependency.
